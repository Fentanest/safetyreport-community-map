Third-party software used by the Excel download (엑셀 다운로드) of 커뮤니티 신고 지도
====================================================================================

The .xlsx file is generated in YOUR browser (a Web Worker) by excelize-wasm. Nothing is uploaded to a server.
The WebAssembly archive is served from this site, built from the pinned npm package below.

1) excelize-wasm 0.1.3 (npm: excelize-wasm, https://github.com/xuri/excelize-wasm)
   — a WebAssembly build of the Go library Excelize (https://github.com/xuri/excelize), BSD 3-Clause.
   It contains the Go runtime glue (wasm_exec.js, Copyright The Go Authors, BSD 3-Clause) and a bundled copy of
   pako (zlib port, MIT: (C) 1995-2013 Jean-loup Gailly and Mark Adler, (C) 2014-2017 Vitaly Puzrin and Andrey Tupitsin).
