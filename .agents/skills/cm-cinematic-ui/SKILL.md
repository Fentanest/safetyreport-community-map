# cm-cinematic-ui

## 읽기
ui-spec.md 전부, screen-by-screen.md, design-system.md, tokens와 원본 이미지 실제열람.
## 실행
1920 grid→1440/2560→390 순으로 shell 구축. KPI/map/insight/3하단카드와 표 hierarchy.
먼저 dark/light 모두 header,filter,card,table,tooltip,drawer를 적용하고 reference UI와 나란히 검토.
분모/기준일·표본 정보를 디자인 때문에 숨기지 않는다. 다색카드 범람·hero 공간 낭비·네온 테두리 금지.
## 출력
token-driven components/styles, screenshots, interactive vertical slice.
## 금지
추상적 '예쁘게' 코멘트만 작성, family assets 무관한테마, 작은글자에정보과밀.
