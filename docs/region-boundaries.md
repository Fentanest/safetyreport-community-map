## 코드 규칙
- 지역 키: ingest가 저장한 표시 키 `<시도약칭> <시군구명>`(예: `서울 중구`)을 **명시 표**로 코드에 맞춘다. 코드 앞자리 추측이나 문자열 접두어로 정하지 않는다.
- 일반구(수원시 장안구 등)는 상위 시로 합친다(키가 시 단위이기 때문).
- 세종은 하나(36110). 키의 두 번째 낱말(동·읍·도로명)과 무관.
- 2026-07-01 변경: 광주광역시·전라남도 → **전남광주통합특별시(12)**, 인천 중구·동구·서구 재편(제물포구 28125, 영종구 28155, 서해구 28275, 검단구 28290).
- 이름이 바뀌거나 옮긴 단위: `인천 남구 → 28177(미추홀구)`, `경북 군위군 → 27720(대구 군위군)`, `인천 동구 → 28125(제물포구)`,
  `충북 청원군 → 43110(청주시)`(2014-07-01 통합. 공유 registry `2014_cheongju` merge_parent, 단일 후계 — 과거 신고는 오늘의 청주시 합계에 넣고 하위 분류로 임의 분배하지 않음).
- 쪼개진 단위(`인천 중구`, `인천 서구`)는 **그 신고의 좌표**가 새 구의 표시 도형 안에 있는지로 정한다. 좌표가 없으면 `지역 미확인`으로 두고 비율로 나누지 않는다.
- 맞는 코드가 없으면 `지역 미확인`(null). 모든 합계에는 그대로 들어가고 지역 목록에 따로 한 줄로 보인다.
- 과거 신고도 오늘(2026-07-01) 단위로 센다. 재분류는 이름·좌표로만 한다.

정본: `contracts/regions/regions-20260701.json`(서버: 코드·이름·분할·개칭·분할 판정용 도형), `contracts/regions/names-20260701.json`(브라우저: 이름만).
서버 `server/regions.ts`, 브라우저 `src/data/regions.ts`. 두 표가 같은 키에 같은 코드를 내는지 `tests/product/regions.test.ts`가 확인한다.

## API와 화면
- `region_code` 조건: 2자리(시도, 그 안의 시군구 포함) 또는 5자리(시군구). 옛 표시 키(`서울 중구`)는 모호하지 않을 때 코드로 바꾸고, 아니면 400.
  브라우저도 URL·관심 지역(localStorage)의 옛 키를 같은 규칙으로 바꾼다.
- `regions[]`: `{level: 'sido'|'sgg'|'unknown', region_code, name, sido_code, …}`. 시도·시군구 행은 각각 원 사실에서 다시 센다(자식 행을 더하거나 평균 내지 않음).
  시도 행 + 미확인 행의 합 = 전체, 한 시도의 시군구 행 합 = 그 시도.
- 지도 점 `region_code`는 5자리 시군구 코드(모르면 null).
- 필터: 시도 → 시군구 두 칸(`RegionSelect`). 지역 목록: 전국에서는 시도, 시도를 고르면 그 안의 시군구, `← … 보기`로 한 단계 위.
- 지도 경계(`src/lib/boundaries.ts`, `src/lib/kakao.ts`):
  - 켜기/끄기 체크박스(기본 켜짐, 이 기기에만 저장 `cm-boundaries`);
  - 넓게 보면 시도, 카카오 레벨 9 이하로 확대하거나 시도를 고르면 시군구(선택한 시도 안만, 아니면 화면에 걸친 것만);
  - 색이 진할수록 신고가 많고, 신고가 없는 곳은 거의 투명(낮은 값처럼 보이지 않게);
  - 올리면 이름·신고 수 카드, 누르면 그 지역만(다시 누르면 한 단계 위);
  - 목록·필터로 고르면 지도가 그 지역으로 이동하지만, 이 이동은 ‘보이는 지역’(bbox) 조건으로 적용하지 않는다;
  - 경계 파일을 못 받으면 안내와 다시 시도만 보이고 마커·통계는 그대로.
- 지역을 고르면 bbox 조건은 지운다(둘을 같이 두면 겹치는 부분만 남아 헷갈림).

## 표시용 가공
mapshaper@0.6.121: UTM-K(EPSG:5179)에서 2% 단순화(keep-shapes) → WGS84 → TopoJSON(quantization 1e5).
브라우저에서 공유 arc 단위로 한 번 더 단순화(시도 0.004°, 시군구 0.0012°; 이웃 경계가 어긋나지 않음). 결과 꼭짓점 시도 약 8.5천, 시군구 전체 약 4.8만.
파일(gzip): 시도 약 190 KB, 시군구 약 300 KB. 경계를 켤 때만 받는다.

## 갱신 절차
1. 새 SGIS 경계·행안부 코드 파일을 문서의 URL에서 직접 받는다(스크립트는 아무것도 내려받지 않는다).
2. 변경 내역(분구·통합·개칭)을 읽고 `split`·`renamed`·통합 규칙을 먼저 고친다.
3. `node scripts/boundaries/build_boundaries.mjs --sgis <zip> --mois <zip>` — sha256이 PINNED와 다르면 멈춘다. 검토 후 PINNED를 바꾼다.
4. 새 버전 폴더(`v<YYYYMMDD>`)로 내보내고 `BOUNDARY_VERSION`·JSON import를 바꾼다. 옛 폴더는 캐시된 페이지를 위해 한동안 남긴다.
5. `npx vitest run tests/product/regions.test.ts tests/product/boundaries.test.ts`, 브라우저 검수.

## 정책
- 경계는 행정구역 표시일 뿐 관할 기관(경찰서·구청)의 범위를 뜻하지 않는다.
- 인구·면적 대비 비율을 만들지 않는다(분모 없음). 색은 현재 조건의 신고 건수 비중만 뜻한다.
