## 구현

읽거나 쓰지 않는다. 열린 카드에서 사용자가 고른 지표는 자료 갱신·테마 변경에도 유지되며, 접고 다시 열면 과태료로 시작한다.

기존 70% 고정 기준의 검정/흰색 글자를 제거했다. 기존 `--text`·`--surface` 토큰을 실제 칸의
색상 램프와 비교해 대비가 큰 글자색을 사용한다. 두 색 모두 4.5:1에 못 미치는 중간 명도 구간에만
작은 토큰 배경을 넣는다. 숫자는 12px로 올렸고, hover 시 칸의 채움색을 유지해 대비를 보존한다.

`visualMap.dimension=2`를 명시해 색상은 비율에 대응한다. 네 번째 값인 답변 건수는 tooltip용으로 유지한다.
기관·담당자 모두 동일 카드에서 적용되며, 수용률/불수용률 선택·표 대안·클릭 필터 경로는 유지했다.
다른 담당 항목의 로직·공유 토큰·package/lock은 변경하지 않았다. `AnalyticsCharts.tsx`는 다른 항목도 담은 파일이나
실제 변경은 import와 `HeatmapCard`에 한정된다.

서버·SQL·계약 변경 없음. 운영 적용·push·배포 없음. 반영 시 프런트 Pages 갱신만 필요하다.
