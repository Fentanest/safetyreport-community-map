# 변경 내역 — scope-statistics-2026-09-29.2

## 통합 범위

이전 scope-statistics-2026-09-29.1의 전체 본문·기존 인수 테스트에 이번 사용자 요구 두 건을 통합했다. 이전 파일을 별도로 전달할 필요가 없다. 파일별·실행 가이드를 뒤로 옮겨 S01~S12의 단일 본문으로 구성했다.

## 이번 추가

1. 월별 비율 단일 select를 독립 checkbox로 변경. 네 비율 동시 표시, 전체/내 시리즈, null/0, 분모 차이, tooltip/표, 설정 보존, 맞춤 통계 레시피 인계.
2. 실제 요청 수명주기에 연결한 상단+영역별 조회 상태. 준비/조회/반영/재시도대기/실패/취소 분리, 마지막 정상 데이터 유지, 늦은 finally 문제·동시 작업·권한 정리·sticky/포커스 회귀 방지.

## 보완된 테스트·자료

- 기존 SC/PI/NV/PG/PV/MS/CH 테스트 유지.
- MT-01~24, LD-01~34, IN-01~06 추가.
- 월별 계산 oracle JSON과 사용자 참고 화면 포함.
- START_PROMPT, README, 요구 매핑, 근거 문서, MANIFEST 제공.

## 하지 않은 일

이 패키지는 프롬프트·테스트 계획·합성 입력 생성물이다. 저장소 수정, 배포, 운영 DB 조회, 브라우저 인수 테스트는 실행하지 않았다. 코드 읽기와 패키지 자체 검증은 SOURCE_NOTES/PACKAGE_CHECKS에 구분해 기록한다.
