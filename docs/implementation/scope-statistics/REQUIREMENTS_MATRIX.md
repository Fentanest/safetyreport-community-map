## 기존 섹션 번호 변경

- 기존 S01~S08: 유지. 관련 부분에 월별·로딩의 연결 요구를 추가.
- 기존 S09 ‘파일별 구현 연결 가이드’: 새 S11.
- 기존 S10 ‘구현 순서와 인수 기준’: 새 S12.
- 새 S09: 월별 비율 다중 선택.
- 새 S10: 실제 조회 상태 가시성.

기존 회귀 방지 항목(비율 지도는 구역색칠, 장기간조회, 필터 활성 강조, 날짜 입력 포커스, 주소/담당자 카드, 별점비교, 1건 일반 표시)을 계속 유지한다. 앞선 모든 작업을 처음부터 재작성하라는 뜻은 아니다.
