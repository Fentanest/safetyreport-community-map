# 통합 인수 테스트 — 선택 범위 상세·맞춤 통계·월별 다중 비율·조회 상태

문서 버전: `scope-statistics-2026-09-29.2`

이 문서는 **수행할 테스트 계획**이다. 이 파일을 작성했다는 사실은 테스트 실행·통과 증거가 아니다. 실제 실행자는 각 항목에 PASS / FAIL / BLOCKED와 증거를 기록한다. 본문 `OPUS_IMPLEMENTATION_PROMPT.md`가 제품 동작의 정본이다.

## 공통 fixture

합성 자료는 production과 분리하고 sample 표시를 유지한다. 실제 사용자 토큰·원번호·신고번호를 결과물에 넣지 않는다.

- 사용자 U1/U2. 전체와 내 신고가 서로 다른 자료.
- 서울특별시 강서구·양천구, 경기도의 지역. 서로 다른 지역에서 같은 법규·담당자명이 나타남.
- 기관 A/B/C. A와 B에 동명이인 담당자, A에 추가 담당자. 0건 선택 대상과 긴 이름의 담당자도 준비.
- 주소 P1/P2와 주소/좌표 결측. 동일 주소의 서로 다른 원본 좌표·다른 주소의 유사 문자열 포함.
- 12년 이상 날짜 범위, 윤년, 기간 앞뒤 경계, 답변일 결측·역전 자료.
- 기준 그룹 G: C=20, A=12, P=3, R=3, 결과미상=2, F=8, W=5. K=18.
- 요약 권한/소유권: 동일 identity 재전송·최신 답변 갱신·계정별 중복·동의 철회·비공개 금액/별점.
- 수용률 가중집계 그룹: A지역 1/1, B지역 9/99 → 상위 10/100=10%.
- 평가: 공개 1점 2건, 3점 1건, 5점 3건 → 평가 6건, 평균 20/6점. 미평가·비공개 별도.
- 차량: 동일 차량이 서로 다른 cell에 등장해 distinct 전체 합계가 cell의 단순 합보다 작도록 설정.
- 후보 API 3페이지 이상; 사용자 선택 기관은 첫 페이지, 나중 추가할 기관은 뒤 페이지에 둠.

## S08 — 통합 성능·배포

- 현재 package.json의 test/build/공개 artifact scan 명령을 확인해 실행한다.
- candidates/detail/pivot/내신고 각각에 auth·scope·version·비공개 필드 테스트를 둔다.
- debounce·abort·429 Retry-After·1회 제한된409 재동기화가 자기증폭하지 않는지 검증한다.
- 쿼리나 후보가 많아도 프론트 raw 원천 다운로드·정책 우회가 없는지 Network와 dist scan으로 확인한다.
- production bundle에 합성 fixture나 private 원번호/계정정보가 포함되지 않는지 확인한다.
- migration/RPC/Edge/Pages 적용 순서와 이전 client 호환성을 검증한다.
- 브라우저 스크린샷은 핀 선택/해제, 서울/강서구 상세, 대상선택창, 피벗표, 같은 조합차트, sticky 이동 전후를 남긴다.
- 기록에는 실행 commit·환경·화면폭·브라우저·테마·데이터 구분(합성/운영)을 적는다. 토큰/원본 식별정보를 제거한다.

## S10 — 조회 상태·로딩 가시성

네트워크·Promise·JSON decode/검증 단계는 테스트 harness에서 지연시킨다. 생산 코드에 지연 sleep을 넣지 않는다. fake timer로 debounce·indicator delay·Retry-After를 따로 검증한다. UI 확인은 slow 1~3초 응답과 더 긴 응답 모두 사용한다.

브라우저 증거에는 **월별 4선·전체/내8선·체크해제 후 표**, **네트워크 대기중/반영후**, **주소 상세만 loading**, **후보 검색중**, **429 대기**, **sticky 이동 전후**를 포함한다. 정지 화면 한 장으로 loading 전 수명주기가 검증됐다고 하지 않는다.
