# 패키지 자체 검사

이 항목은 문서·압축파일의 구성 검사다. 앱 구현·단위 테스트·운영 조회·브라우저 검수 통과를 뜻하지 않는다.

- 이전 핵심 문서2개 전체 읽기 후 통합.
- 기존 S01~S08 섹션 유지 및 관련 요구 추가.
- S01~S12 제목이 각1회 존재.
- 기존 고유 테스트 86개 유지, 신규 MT/LD/IN 포함 고유 테스트 150개.
- Markdown fenced code block 짝 검사.
- 월별 oracle JSON 파싱과 null/0/분모 계산 검증.
- 참고 이미지는 runtime에서 실재 파일 확인 후 복사.
- MANIFEST.sha256 생성, zip CRC/파일명/로컬 참조/해시 대조는 패키지 생성 시 별도로 수행.

원본 구현지시서 SHA256: `55cdb1d92d7870428134e9cfb1af0d5bb6df0a38fa017a2cb7eb149f7573601d`
원본 인수테스트 SHA256: `dd23b79df9efc3c3d2e9c0149c73f8b1b58ac31e92d5933c4c7cb3c9c5d0e8cf`

검사자: 이번 문서 생성 과정. 구현할 작업은 전부 Opus의 실제 환경에서 별도 실행·보고해야 한다.
