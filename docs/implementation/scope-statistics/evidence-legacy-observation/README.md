# 이전 관찰 기록 (39552e3, 판정 없음)

이 폴더는 이전 라운드(커밋 `39552e3`) 브라우저 스크립트가 남긴 **관찰값과 스크린샷**이다. 당시 스크립트는 기대값을 자동으로 판정하지 않았고, 예외를 삼킨 뒤 종료 코드 0으로 끝났다. 따라서 이 폴더의 파일은 PASS 증거가 아니다.

판정 결과는 `../closeout-evidence/`의 `runs/<run_id>.json`을 본다. 그 파일은 assertion 기반이고, 실패가 있으면 종료 코드가 1이다.

모든 기록은 합성 자료와 MOCK 카카오 SDK로 만든 것이다.
