# Opus에게 전달할 시작 프롬프트

아래 내용을 그대로 전달한다. 실제 코드는 최신 checkout에서 작업하고, 이 문서 경로는 파일 배치에 맞춘다.

```text
대상 저장소는 Fentanest/safetyreport-community-map이고 이번 작업 총괄은 Opus다.

AGENTS.md와 PROJECT_RULES.md를 읽은 뒤, 다음 통합 문서 두 개를 읽고 구현을 진행해.
- docs/implementation/scope-statistics/OPUS_IMPLEMENTATION_PROMPT.md
- docs/implementation/scope-statistics/ACCEPTANCE_TESTS.md

이번 정본 버전은 scope-statistics-2026-09-29.2다.
이전 .1 문서의 선택 범위 상세·핀·스크롤·맞춤 통계·대상선택·표/그래프 전환에
월별 복수 비율과 실제 조회 상태 표시를 합친 완본이다.
이전 프롬프트를 별도로 찾아 읽거나 추가 메모만 적용할 필요는 없어.
기준 커밋으로 되돌리지 말고 최신 코드·미커밋 변경을 보존해.
이미 정상 구현된 기능은 검사 후 유지하고 미구현·회귀·추가 요구를 완성해.

필수 범위:
1. 핀이 없어도 전국·시도·시군구·현재 적용 지도 범위의 상세를 오른쪽에서 보기.
2. 핀 재클릭·해제 버튼·Esc·진짜 지도 빈 클릭으로 해제하고, 선택 핀을 명확히 강조.
3. 실제 sticky 영역 높이를 반영한 sidebar/anchor 이동과 지도 상태 복원.
4. 좌측과 모바일에 ‘통계’ 진입, 별도 화면 H1은 ‘맞춤 통계’. Pages 직접 진입/새로고침 지원.
5. 행·열·지표·필터·전체/내 신고의 피벗 집계, 허용 필드 registry와 서버 검증.
6. 기관·담당자·지역·법규의 검색형 비교 대상 다중 선택과 적용.
7. 현재 조합을 보존하는 표/그래프 전환, 호환되는 차트 추천·수동변경, 동일결과 보장.
8. 월별 추이의 처리결과 비율을 체크박스로 바꿔 수용률/불수용률/일부수용률/
   과태료처분율을 여러 개 겹쳐 보기. 내 비교 ON이면 지표마다 전체 실선·내 점선,
   최대8선과 같은 선택의 표/tooltip/통계 인계까지 구현.
9. 실제 조회중에는 상단 공통 상태+관련 패널의 로딩을 보이게 하고 마지막 정상 화면은 유지.
   준비·조회·검증/반영·재시도대기·실패·취소를 request lifecycle에 연결.
   A요청 finally가 최신B요청 busy를 끄거나 무한spinner·가짜진행률이 생기면 안 됨.
   로컬 checkbox/캐시/표현 전환에는 가짜 DB로딩·재조회 금지.

‘월별 네 지표 선택’은 지도 모드 버튼이나 주소 차트 라디오를 바꾸는 지시가 아니다.
수용계열은 K=A+P+R, 과태료처분율은 C=답변완료가 분모다.
null과 정상0, 자료없음과 조회중, 전체와 내 신고를 분리해.

서버 집계→API→DTO/Zod→client→state→화면→테스트까지 연결하고,
CSS만 바꾸거나 mock UI만 만든 뒤 완료로 보고하지 마.
기존 인증·동의·마스킹·원본좌표·identity·비율구역지도·장기간조회·날짜포커스는 유지해.

fixtures/monthly-rates.example.json은 합성 테스트 oracle이고 운영 fallback이 아니다.
references/current-monthly-trend.png는 수정 전 참고 화면이다.
구현·자동검사·실제 브라우저에서 느린조회/레이스/취소/429/0건/1건/두계정을 검수해.

마지막에 S01~S12별 변경 파일, 실제 배선, 테스트·브라우저 증거,
남은 migration/Edge/Pages 적용을 보고해.
문서 작성이나 로컬fixture만으로 운영검증 완료라 하지 마.
필요한 운영 권한은 별도 확인하되 로컬에서 가능한 구현은 끝내.
```
